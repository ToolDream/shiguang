# 使用指南

拾光截图在 Windows x64（10 1703 或更新）上运行。启动后只在通知区域保留一个图标，关闭设置窗口不会退出，截图热键始终可用。

拾光界面跟随 Windows 应用的浅色或深色模式，高对比度时优先使用系统配色。主题只改变设置和截图界面，不改变冻结画面、标注原色或导出结果。

## 截图与标注

- 按全局热键（默认 **Ctrl + Shift + S**），或右键托盘图标选「区域截图」。此时只显示桌面遮罩，不动剪贴板。
- 左键拖选，松开即锁定选区，随即进入编辑；工具栏在选区下方，靠近屏幕边缘时会自动换位。
- 工具栏提供矩形、圆、椭圆、三角形、菱形、箭头、画笔、文字和颜色。撤销、重做只作用于本次编辑。
- 文字工具（T 图标）在选区内打开录入框，可直接使用中文输入法；按 **Enter** 或切换工具把文字加入截图。
- 裁剪、合成与导出都按物理像素处理，错位显示器之间既未覆盖也未标注的区域在 PNG 中保持透明。

## 完成、取消与重试

- 文字录入框之外按 **Enter** 复制到剪贴板，按 **Ctrl + S** 另存 PNG，也可点工具栏右侧的复制、保存图标。
- 另存不覆盖已有文件：目标存在时本次保存失败，原文件不变，换名重试即可。
- 取消另存、剪贴板被占用或写入失败时，选区和标注都还在，可以重试；托盘另存不受当前编辑会话影响。
- 按 **Esc** 放弃本次编辑，不替换上一次截图或剪贴板（输入法组字时 Esc 可能先交给输入法处理）。

## 托盘与设置

- 应用是单实例：重复启动不会再出现第二个图标。图标可能折叠在「^」中，点击或右键菜单可打开「设置」。
- 设置窗口标题栏可拖动，带「最小化」与「关闭」；「关闭」等同于隐藏，热键继续有效。窗口不能最大化或拉边调整大小。
- 需要彻底退出时，用设置窗口或托盘菜单里的「退出拾光」。

### 登录时启动

设置中的「登录 Windows 时启动拾光」默认关闭，仅影响当前用户，不需要管理员权限。打开后，拾光在登录时直接驻留通知区域，不会弹出设置；关闭开关不会退出当前实例。

「已注册」只表示当前路径已登记到 Windows 启动项。Windows 的启动应用设置、任务管理器或管理员策略仍可阻止它启动；拾光不会改动这些设置。移动 EXE 前请先在旧位置关闭开关；新位置不会覆盖或删除旧路径的同名项。若旧路径已不可用，可先在 Windows 的启动应用设置中停用旧项。

### 软件更新

支持自动更新的签名构建会定时检查，间隔为 24 小时。「最近检查」显示最近一次检查尝试的本地时间，失败也会记录；设置不提供手动检查按钮。

- 默认使用「测试版」通道，也能收到比当前版本新的正式版。选择「正式版」后只接收正式版，不会自动降级；切换通道不会立即发起检查。
- 默认开启「自动下载更新」。关闭后，发现新版本时可以点「下载更新」。下载中显示活动进度，不显示百分比；下载失败可以点「重试下载」。
- 下载完成后，在设置或托盘选择「重启更新」。普通退出不安装更新。若仍在截图、编辑、保存或录入快捷键，请先完成当前操作，再重试。

旧版首次升级需手动下载并使用支持更新的整套便携包。没有可信签名配置的开发构建或历史包不能自动安装；公开发布状态见 [构建与发布流水线](release.md)。

如果更新中断且拾光打不开，退出所有拾光进程，运行便携目录中的
`Shiguang-Recovery/恢复拾光.exe`。恢复不需要联网或管理员权限；成功后再重新打开拾光。


## 更换快捷键

1. 在设置中点击当前组合键旁的「更改」。上一次录入失败后，这个按钮会变成「重新录入」。
2. 保持设置窗口在前台，按下新组合键；切换走焦点后录入不再生效。
3. 按 **Esc** 取消录入。

组合键必须包含 **Ctrl**、**Alt** 或 **Win** 中至少一个，可再加 **Shift**。主键支持字母、数字、**F1–F24（F12 除外）**、空格，以及 PgUp / PgDn / Home / End / 方向键 / Ins / Del。

系统保留、已被占用或写入失败时保留原快捷键，并在设置里说明原因，例如「ⓘ 新组合键已被占用，仍使用 Ctrl + Shift + S。」或「新组合键已被占用，当前没有可用快捷键。」。成功后写入当前用户配置，重启仍生效。

## 限制

- 仅支持 Windows x64（Windows 10 1703 或更新）。
- 屏幕采集用 GDI 逐屏读取，各显示器不保证同一刷新时刻，快速变化的画面可能有屏间时间差。
- 受保护内容与 UAC 安全桌面不在支持范围。
- 不提供截图历史或云同步，只保留内存中的最近一次结果。
- 可从 [GitHub Releases](https://github.com/ToolDream/shiguang/releases) 下载便携包，也可从源码构建，见 [环境与构建](build.md)。
